# 📘 Student Database Management System

## 📌 What I Built

I created a **Student Database Management System** to practice **database design, SQL queries, and normalization**. The project manages student information, subjects, grades, and attendance in a structured way.

## 🎯 Why I Built It

* To strengthen my understanding of **RDBMS concepts** (tables, primary keys, foreign keys, relationships).
* To practice **data modeling** and simulate a real-world school management system.
* To explore how **SQL queries (JOIN, GROUP BY, AVG, COUNT, VIEWS, etc.)** can analyze student performance and attendance.

## 🛠️ How I Built It

1. **Designed Tables**:

   * `students` → stores student details.
   * `subjects` → stores subject names.
   * `grades` → records student exam scores with exam type and date.
   * `attendance` → tracks daily student presence/absence.

2. **Normalization**: Structured tables up to **3NF** to reduce redundancy and maintain data consistency.

3. **Inserted Sample Data**: Added 20+ students, subjects, multiple grades, and attendance records.

4. **SQL Queries**:

   * Used **JOINs** to combine student, subject, and grade data.
   * Calculated **average scores** and **attendance percentages** using `AVG()` and `COUNT()`.
   * Created **views** for quick access to performance and attendance reports.

5. **Analysis & Insights**:

   * Found top-performing students and subjects.
   * Checked attendance trends over multiple days.
   * Built views to summarize student performance.
